5. Copy setup to another device

Makes a code with the form connection (and, if you want, the bell schedule). Paste it into another kiosk's setup. It never includes student names, the room name, or the PIN.

6. Erase this device

Removes the form connection, room, PIN, class lists and any check-ins still waiting to send. Use this before giving the device to someone else.
