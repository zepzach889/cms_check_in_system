Teacher setup on this device

1. Connect your Google Form

In Google Forms, open the ⋮ menu › Get pre-filled link. Type the word room in the Room question, student in Student, type in Type, reason in Reason class in Class, time in Kiosk time, minutes in Minutes out, late in Minutes late, and pass in Pass. Click Get link, copy it, and paste it here.

Check that each answer box is matched to the right question:

2. This room

Comes from the school's bell schedule automatically. Change it here only for a surprise schedule; it goes back to normal tomorrow.

A web page can't fully lock a device. For a real lock, see "Locking the device" in the guide.

Teacher PIN

3. Class lists

Pick the period and the times come from the school bell schedule. Names are saved only in this browser — never on the website. Paste names one per line (“Maya Rivera” or “Rivera, Maya”), or upload a CSV file with First and Last name columns.

Add a class

4. Test & send status

Waiting to send0 check-ins

Google doesn't reply when a check-in arrives, so the kiosk keeps a copy and retries if the internet drops. After a test, always look in your Sheet. The Sheet is the real record.

Today on this device

5. Copy setup to another device

Makes a code with the form connection and, if you want, the classes. Paste it into another kiosk's setup. It never includes the room name, PIN, or hall pass settings.

Only include names when you're moving a roster between devices yourself. The code isn't secret-proof: don't email it widely or post it anywhere students or others could see.

6. Hall passes

If a student doesn't tap "I'm back," the pass closes itself at the end of the class (or after an hour) and the Sheet says "Not signed back in."

Out right now

7. Erase this device

Removes the form connection, room, PIN, class lists, hall pass settings and any check-ins still waiting to send. Use this before giving the device to someone else.
